## GPIO Pinout

| Pin    | Function                      |
| ------ | ----------------------------- |
| GPIO1  | LED (inverted)                |
| GPIO3  | Button                        |
| GPIO4  | Relay - Socket 3              |
| GPIO5  | Relay - Socket 4 (Right Most) |
| GPIO12 | Relay - Socket 2              |
| GPIO13 | Relay - Socket 1 (Left Most)  |
| GPIO14 | Relay - USB                   |
