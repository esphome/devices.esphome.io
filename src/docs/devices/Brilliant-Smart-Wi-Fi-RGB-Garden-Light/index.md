## General Notes

This configuration is for the [Brilliant Smart Wi-Fi RGB Garden Light](https://brilliantlighting.com.au/products/brilliant-black-botanic-smart-wi-fi-rgb-garden-light-kit)
which comes as a kit with 4 LED RGB spotlights, a transformer and the controller.

![Brilliant Smart Wi-Fi RGB Garden Light Kit](./Brilliant-Smart-Wi-Fi-RGB-Garden-Light.jpg "Brilliant Smart Wi-Fi RGB Garden Light Kit")

## GPIO Pinout

| Pin    | Function      |
| ------ | ------------- |
| GPIO4  | Red Channel   |
| GPIO12 | Green Channel |
| GPIO14 | Blue Channel  |
